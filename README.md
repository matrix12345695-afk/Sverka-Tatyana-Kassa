# Бот сверки кассы: Billz ↔ Google Sheets

Каждый день в 21:00 (Ташкент) бот сверяет все чеки Billz за день с листом «Касса …» в таблице и присылает в Telegram: ✅ всё сходится или ❌ что именно не так — со ссылками на чек и строку таблицы.

## Какие отчёты приходят

| Когда | Отчёт | Что в нём |
|---|---|---|
| Каждый день, 21:00 | **Дневной** | Суммы по способам оплаты (Billz / таблица), специалисты с расхождением, чеки: нет в таблице / нет в Billz / другой специалист / другой способ оплаты, **удалённые чеки** (⚠️ если удалён через сутки и позже), частичные оплаты (возможные долги), ошибки в таблице (строка без суммы, неверный «Итог»), итог с начала месяца |
| 1-го числа, 21:00 | **Месячный** | То же за весь прошлый месяц + итоги по всем специалистам + дни с расхождением |
| Понедельник, 21:00 | **Выборочный** | 5 случайных чеков за прошлую неделю — сверить руками с деньгами (касса, терминал, банк) |
| По команде | Любой | `/today`, `/day 12.11`, `/period 01.10 31.10`, `/month 10.2026`, `/spot 10` |

## Что нужно один раз настроить

### 1. Бот в Telegram
1. В Telegram откройте **@BotFather** → `/newbot` → придумайте имя → получите **токен**.
2. Скопируйте `.env.example` в `.env`, вставьте токен в `TELEGRAM_BOT_TOKEN`.

### 2. Вход в Billz (токен, раз в 14 дней)
Секретного ключа API нет, поэтому бот работает с токеном входа — тем же, с которым работает сайт Billz. Он действует **14 дней**.

Как получить токен (на компьютере, в Chrome):
1. Откройте свой Billz (`https://<поддомен>.billz.ai`) и войдите.
2. Нажмите **F12** → вкладка **Application** (Приложение) → слева **Local Storage** → адрес вашего Billz.
3. Найдите строку **access_token**, скопируйте её значение (длинная строка `eyJ...`).
4. В **личном** чате с ботом отправьте: `/billz_token eyJ...`

Бот сразу удалит сообщение с токеном и ответит, до какой даты он действует.
За 3 дня до окончания бот каждый день в 10:00 напоминает обновить токен. `/status` — посмотреть срок.

⚠️ Токен даёт доступ к Billz от вашего имени: никому его не пересылайте, кроме своего бота.
Если нажать «Выйти» на сайте Billz, токен может перестать работать — тогда пришлите новый.

### 3. Доступ к Google-таблице (сервисный аккаунт)
Таблица закрытая, поэтому боту нужен свой «Google-пользователь»:
1. https://console.cloud.google.com → создайте проект → **APIs & Services → Enable APIs** → включите **Google Sheets API**.
2. **IAM & Admin → Service Accounts → Create** → затем у аккаунта **Keys → Add key → JSON** — скачается файл.
3. Положите файл рядом с `bot.py` под именем `service_account.json`.
4. В таблице «Кассовые записи» нажмите **Поделиться** и добавьте почту сервисного аккаунта (вида `...@...iam.gserviceaccount.com`) с правом **Читатель**.

### 4. Кому слать отчёты
1. Запустите бота (см. ниже) и напишите ему `/id` — он ответит ID чата.
2. Впишите ID в `ALLOWED_CHAT_IDS` (несколько — через запятую; можно ID группы) и перезапустите.
Остальным людям бот ничего не покажет.

## Запуск

```
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python bot.py
```
На Windows можно просто запустить `start_bot.bat`.

**Бот должен работать постоянно** — иначе в 21:00 отчёт не придёт. Варианты:
- на компьютере, который всегда включён (добавить `start_bot.bat` в автозагрузку);
- на сервере / VPS (надёжнее).

Первая проверка после настройки: отправьте `/status`, затем `/day <день, который вы уже сверяли вручную>` и сравните с ручной сверкой.
Настройки организации (ID компании, поддомен, ID таблицы) — в `.env`; специалисты и листы — в `config.json` (создаётся из `config.example.json` при первом запуске). Оба файла в репозиторий не попадают.

## Новый месяц
Бот сам ищет лист «Касса <месяц> <год>». Если лист назван иначе — отправьте `/sheet 12.2026 <gid>` (gid — число после `#gid=` в адресе листа).

## Специалисты
Соответствие имён в таблице и в Billz — в `config.json` → `specialists`. Пришёл новый сотрудник: добавьте строку `"Имя Фамилия как в Billz": ["как пишут в таблице"]`.

## Как сверяется
- Каждая оплата (день, сумма, специалист, способ оплаты) из таблицы ищется среди чеков Billz.
- Совпало всё — ✅. Совпали день и сумма, но другой специалист/способ — показывается как расхождение. Нет пары — «нет в Billz» / «нет в таблице».
- Возврат гасит продажу того же клиента на ту же сумму.
- День чека — дата **проведения** (как в отчётах Billz).
- Удалённые чеки ищутся за 31 день назад: видно и удаление «задним числом».
